## **使用须知：**

1、为保障题目原创权，题目署名一经保存不可更改，请慎重

2、PartC要点请用英文逗号隔开，否则无法识别

3、手机版批改与历史记录功能尚不稳定，可能无法批改与回放录音，请做好预期

4、PartA上传的视频需附带字幕

5、若手机麦克风无法识别，请自行在设置中开启软件麦克风使用权限

6、电脑版必须使用全英文路径

## **SoloTalk手机版操作指南：**

### **1、   下载**

如果你从Q群下载SoloTalk，请打开群聊点击右上角三道杠，下滑找到群应用，点击群文件，找到结尾为apk.1的文件，点击右侧三个点，选择保存到手机。然后退出QQ，打开文件管理。这时“最近”一栏会出现该文件（若没有出现无需着急，可能只是我没有刷新成功下滑不一定有用，等待片刻即可），长按→更多→重命名，删除文件名中的.1，确定后会弹出是否改变的提示，确定即可。点击文件，选择已了解风险（出现该提示是由于该应用未上架应用商城不是软件有病毒）→继续安装→输入密码→完成

不出意外做到这步时你已成功下载SoloTalk。

### **2、练习模式使用**

打开软件时你会看到三个按键，编辑模式，练习模式，与历史记录。之所以先讲练习模式，是因为该功能是模拟听说考试的主要功能。要注意的是，该功能只是个载体，并没有包含E听说丰富的题库，所有题目均需要通过编辑模式制作并下载完文件后导入，因此该Q群的建立初衷也是供大家分享自己创造的题目，以壮大SoloTalk的题库系统。如果你现在想体验此功能，可以从群文件中的共创题目文件夹下载.solo测试题目。方法与之前相同。如果你是华为设备，打开SoloTalk→测试模式，会打开文件选择界面，选择文件名为QQ的文件夹，点击.solo文件，即可按流程指引开始模考，若是小米设备则比较复杂，需要根据精华消息与群文件的视频指引进行导入。

要注意考试结束后会进行批改，不要马上退出，一般在30秒以内完成，电脑批改仅作为参考，最好自己听录音，对一下答案。

### **3、编辑模式的使用**

现阶段SoloTalk的题库非常匮乏，需要大家的共同创作分享到群文件。打开编辑模式后出现以下界面，可以为你的题目命名与署名。

#### **①PartA的编辑**

要导入视频，点击选择按键，会打开与练习模式相同的文件选择界面，点击左上角三条杠，点击图库（注意是图库不是视频）即可选择相册中的视频进行上传

上传视频后需要在下方提示输入原文文本的文本输入栏输入模仿朗读的文本，可以尝试借助AI上传视频后让其输出视频文本。如果你在B站等平台上看到合适的模仿朗读视频，可尝试通过网站https://snapany.com/zh/
在输入栏输入视频网址→提取视频图片→下载视频以获得视频文件。

#### **②PartB的编辑**

根据提示输入你在正常听说考试中见到的各个部分（如果你还没有考过一次高中的听说考试，建议查找观看全流程视频，或通过SoloTalk已有的测试题了解听说过程）。注意三问中文提示指的是你需要翻译的中文句子。英文机答指的是翻译三问后你听到的听力文本，标准答案指的是三问的标准翻译，如果你没有题目，可以尝试让AI搜索相关题目，并按照该格式输出，以便你的填写。

#### **③PartC的编辑**

与PartB类似，根据提示输入你在正常听说考试中见到的各个部分，听力材料可以选择上传音频，方法与视频的上传类似，当然，大部分情况是你没有音频文件，请选择电脑TTS朗读，并上传故事全文文本，答案要点部分请输入，文本中的关键短语，不要附带除英文逗号外的标点符号，每个短语之间，用英文逗号隔开，同样，你可以选择将全文文本上传给AI后，让其为你输出要点。

### **3、历史记录的使用**

当你完成一次考试后，点击历史模式应该可以查看你的考试记录，与你考试结束后看到的一致，但该功能不稳定，很可能会丢失记录，建议在考试结束后截图保存当时的记录。

## **SoloTalk电脑版使用指南**

### **1、下载**

如果在群文件下载SoloTalk，请打开群文件下载最新版的zip文件解压（若不会解压请看[电子扫盲课—网盘下载压缩文件及解压缩教学_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV11w4m1y7kA/?spm_id_from=333.1387.search.video_card.click&vd_source=615d82af1537369c91627ecf19af93ca)）解压后双击打开SoloTalk.exe即可打开软件

### **2、练习模式与模考模式的使用**

打开软件时你会看到四个按键，编辑模式、练习模式、模考模式与历史记录。之所以先讲练习模式，是因为该功能是模拟听说考试的主要功能。要注意的是，该功能只是个载体，并没有内置像E听说一样丰富的题库，所有题目均需要通过编辑模式制作并保存完文件后导入，因此该Q群的建立初衷也是供大家分享自己创造的题目，以壮大SoloTalk的题库系统。如果你现在想体验此功能，可以从群文件中的共创题目文件夹下载.solo测试题目进行尝试。

点击练习模式按键后会弹出文件选择窗口，根据下载地址找到下载的.solo文件双击打开即可根据流程开始考试。

练习时中途返回主页后相当于暂停，若不关闭软件再次选择相同题目文件会从退出的题目开始，中断的听力会重新播放，若在录音时中断会返回上一次听力材料重新播放（若不想再听一遍可以点击跳过）。

模考模式与练习模式基本一致，但会改为全屏模式，不可中途退出，不可进行跳过或上一步操作。

考试完成后会进行批改，批改结果与答案在历史记录查看。
